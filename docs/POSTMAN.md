# Postman — показать запросы

1. Import → выбери `postman_collection.json`.
2. В переменных коллекции укажи `username` и `password` своего пользователя. `base_url` = `http://127.0.0.1:8000`.
3. Отправь Login. Скрипт коллекции сохранит access и refresh автоматически.
4. Выполняй запросы сверху вниз. Создание клиента сохранит `client_id`, создание счёта — `account_id`.
5. PUT отправляет полный набор изменяемых полей. GET принимает фильтры в Params. POST/PUT — Body → raw → JSON.
6. Удаляй сначала счёт, затем клиента. Коллекция использует отдельный вымышленный ИИН; при повторном незавершённом запуске возможна ошибка дубликата 400.
7. Для 401 выбери No Auth у GET Clients; для 400 поставь ИИН `123`; для 404 запроси `/api/clients/999999/`.

Не экспортируй коллекцию с настоящими паролями или токенами.
